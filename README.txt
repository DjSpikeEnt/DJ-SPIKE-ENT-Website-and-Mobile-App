DJ SPIKE ENT — iPhone PWA Test Preview (v0.1)

This is a separate test deployment. It does not overwrite your current live site.

To deploy manually:
1. In Netlify, create a NEW site (do not select your existing djspikeentnj site).
2. Use Netlify's manual deploy / drag-and-drop deploy and upload the unzipped folder contents.
3. Open the new Netlify URL in Safari on your iPhone.
4. Tap Share, then Add to Home Screen, then Add.

This first preview makes the existing landing-page experience installable and adds app-style bottom navigation. The mixes link opens YouTube. The existing quote form still opens a pre-filled email. Live Supabase gallery, customer likes, video compression, and connected booking workflows are not included in this first preview yet.
